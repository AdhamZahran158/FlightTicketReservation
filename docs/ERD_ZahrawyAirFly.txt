================================================================================
ENTITY 1: TENANT
================================================================================
Description: Represents an airline company registered on the SaaS platform.
             Each tenant operates independently with isolated data.

+---------------------+-----------------+------+--------+-----------------------+
|     Attribute       |    Data Type    | NULL | Key    | Description           |
+---------------------+-----------------+------+--------+-----------------------+
| Id                  | UNIQUEIDENTIFIER| NO   | PK     | Primary key           |
| CompanyName         | NVARCHAR(200)   | NO   |        | Airline company name  |
| Subdomain           | NVARCHAR(100)   | NO   | UNIQUE | URL subdomain         |
| LogoUrl             | NVARCHAR(500)   | YES  |        | Company logo URL      |
| ContactEmail        | NVARCHAR(256)   | NO   |        | Company contact email |
| Currency            | NVARCHAR(10)    | NO   |        | Default currency code |
| IsActive            | BIT             | NO   |        | Active/disabled flag  |
| CreatedAt           | DATETIME2       | NO   |        | Record creation date  |
| UpdatedAt           | DATETIME2       | YES  |        | Last update date      |
| IsDeleted           | BIT             | NO   |        | Soft delete flag      |
+---------------------+-----------------+------+--------+-----------------------+

Relationships:
  - TENANT (1) ----< (M) USER           : A tenant has many users
  - TENANT (1) ----< (M) AIRCRAFT       : A tenant owns many aircraft
  - TENANT (1) ----< (M) FLIGHT         : A tenant operates many flights
  - TENANT (1) ----< (M) POLICY         : A tenant defines many policies
  - TENANT (1) ----< (M) TAX_FEE        : A tenant configures many taxes/fees
  - TENANT (1) ----< (M) OFFER          : A tenant creates many offers
  - TENANT (1) ----< (M) DISCOUNT       : A tenant creates many discount codes
  - TENANT (1) ----< (M) NOTIFICATION   : A tenant sends many notifications

ENTITY 2: AIRPORT
================================================================================
Description: Represents a global airport. Shared across all tenants. Contains
             IATA/ICAO codes, location data, and timezone information.

+---------------------+-----------------+------+--------+-----------------------+
|     Attribute       |    Data Type    | NULL | Key    | Description           |
+---------------------+-----------------+------+--------+-----------------------+
| Id                  | UNIQUEIDENTIFIER| NO   | PK     | Primary key           |
| IataCode            | NVARCHAR(3)     | NO   | UNIQUE | 3-letter IATA code    |
| IcaoCode            | NVARCHAR(4)     | YES  | UNIQUE | 4-letter ICAO code    |
| Name                | NVARCHAR(300)   | NO   |        | Full airport name     |
| City                | NVARCHAR(200)   | NO   |        | City name             |
| Country             | NVARCHAR(200)   | NO   |        | Country name          |
| CountryCode         | NVARCHAR(3)     | NO   |        | ISO country code      |
| Timezone            | NVARCHAR(100)   | NO   |        | IANA timezone ID      |
| Latitude            | DECIMAL(9,6)    | YES  |        | Geographic latitude   |
| Longitude           | DECIMAL(9,6)    | YES  |        | Geographic longitude  |
| IsActive            | BIT             | NO   |        | Active flag           |
| CreatedAt           | DATETIME2       | NO   |        | Record creation date  |
| UpdatedAt           | DATETIME2       | YES  |        | Last update date      |
| IsDeleted           | BIT             | NO   |        | Soft delete flag      |
+---------------------+-----------------+------+--------+-----------------------+

Relationships:
  - AIRPORT (1) ----< (M) FLIGHT (as Origin)       : Airport is origin of many flights
  - AIRPORT (1) ----< (M) FLIGHT (as Destination)   : Airport is destination of many flights

Relationships:
  - USER (M) >---- (1) TENANT          : User belongs to a tenant
  - USER (1) ----< (M) BOOKING         : User makes many bookings

ENTITY 6: FLIGHT
================================================================================
Description: A scheduled flight operated by an airline. Links to aircraft,
             origin airport, and destination airport. Contains pricing and 
             baggage configuration.

+---------------------+-----------------+------+--------+-----------------------+
|     Attribute       |    Data Type    | NULL | Key    | Description           |
+---------------------+-----------------+------+--------+-----------------------+
| Id                  | UNIQUEIDENTIFIER| NO   | PK     | Primary key           |
| TenantId            | UNIQUEIDENTIFIER| NO   | FK     | Ref: Tenant.Id        |
| AircraftId          | UNIQUEIDENTIFIER| NO   | FK     | Ref: Aircraft.Id      |
| OriginAirportId     | UNIQUEIDENTIFIER| NO   | FK     | Ref: Airport.Id       |
| DestinationAirportId| UNIQUEIDENTIFIER| NO   | FK     | Ref: Airport.Id       |
| FlightNumber        | NVARCHAR(20)    | NO   |        | e.g., "ZA-1042"      |
| DepartureUtc        | DATETIME2       | NO   |        | Departure time (UTC)  |
| ArrivalUtc          | DATETIME2       | NO   |        | Arrival time (UTC)    |
| Gate                | NVARCHAR(10)    | YES  |        | Departure gate        |
| Terminal            | NVARCHAR(10)    | YES  |        | Terminal number       |
| Status              | NVARCHAR(20)    | NO   |        | Flight status (enum)  |
| BasePriceEconomy    | DECIMAL(18,2)   | NO   |        | Economy class price   |
| BasePriceBusiness   | DECIMAL(18,2)   | NO   |        | Business class price  |
| BasePriceFirst      | DECIMAL(18,2)   | NO   |        | First class price     |
| MaxBaggageKg        | INT             | NO   |        | Max baggage allowed   |
| FreeBaggageKg       | INT             | NO   |        | Free baggage included |
| ExtraBaggagePerKg   | DECIMAL(18,2)   | NO   |        | Extra baggage rate/kg |
| CreatedAt           | DATETIME2       | NO   |        | Record creation date  |
| UpdatedAt           | DATETIME2       | YES  |        | Last update date      |
| IsDeleted           | BIT             | NO   |        | Soft delete flag      |
+---------------------+-----------------+------+--------+-----------------------+

Relationships:
  - FLIGHT (M) >---- (1) TENANT                     : Flight belongs to tenant
  - FLIGHT (M) >---- (1) AIRCRAFT                   : Flight uses an aircraft
  - FLIGHT (M) >---- (1) AIRPORT (as Origin)         : Flight departs from
  - FLIGHT (M) >---- (1) AIRPORT (as Destination)    : Flight arrives at
  - FLIGHT (1) ----< (M) FLIGHT_SEAT                : Flight has many seats
  - FLIGHT (1) ----< (M) BOOKING                    : Flight has many bookings
  - FLIGHT (1) ----< (M) FLIGHT_OFFER               : Flight has many offers

| MaxUsageCount       | INT             | NO   |        | Max times usable      |

| IsDeleted           | BIT             | NO   |        | Soft delete flag      |
+---------------------+-----------------+------+--------+-----------------------+

  - OFFER (M) >---- (1) TENANT                     : Offer belongs to tenant
  - OFFER (1) ----< (M) FLIGHT_OFFER               : Offer applied to flights


================================================================================
ENTITY 8: FLIGHT_OFFER (Junction Table)
================================================================================
Description: Links offers to flights in a many-to-many relationship.
             A flight can have multiple offers, and an offer can apply to
             multiple flights.

+---------------------+-----------------+------+--------+-----------------------+
|     Attribute       |    Data Type    | NULL | Key    | Description           |
+---------------------+-----------------+------+--------+-----------------------+
| Id                  | UNIQUEIDENTIFIER| NO   | PK     | Primary key           |
| FlightId            | UNIQUEIDENTIFIER| NO   | FK     | Ref: Flight.Id        |
| OfferId             | UNIQUEIDENTIFIER| NO   | FK     | Ref: Offer.Id         |
| CreatedAt           | DATETIME2       | NO   |        | Record creation date  |
+---------------------+-----------------+------+--------+-----------------------+

Relationships:
  - FLIGHT_OFFER (M) >---- (1) FLIGHT  : Belongs to a flight
  - FLIGHT_OFFER (M) >---- (1) OFFER   : Belongs to an offer

Constraints:
  - UNIQUE (FlightId, OfferId) -- No duplicate offer on same flight

ENTITY 10: FLIGHT_SEAT
================================================================================
Description: Represents a specific seat on a specific flight. Created when
             a flight is scheduled. Tracks real-time booking status.

+---------------------+-----------------+------+--------+-----------------------+
|     Attribute       |    Data Type    | NULL | Key    | Description           |
+---------------------+-----------------+------+--------+-----------------------+
| Id                  | UNIQUEIDENTIFIER| NO   | PK     | Primary key           |
| FlightId            | UNIQUEIDENTIFIER| NO   | FK     | Ref: Flight.Id        |
| SeatId              | UNIQUEIDENTIFIER| NO   | FK     | Ref: Seat.Id          |
| Status              | NVARCHAR(20)    | NO   |        | Available/Booked/etc. |
| PriceOverride       | DECIMAL(18,2)   | YES  |        | Custom price for seat |
| LockedByUserId      | UNIQUEIDENTIFIER| YES  | FK     | Ref: User.Id (temp)   |
| LockedUntil         | DATETIME2       | YES  |        | Lock expiry time      |
| CreatedAt           | DATETIME2       | NO   |        | Record creation date  |
| UpdatedAt           | DATETIME2       | YES  |        | Last update date      |
| IsDeleted           | BIT             | NO   |        | Soft delete flag      |
+---------------------+-----------------+------+--------+-----------------------+

Relationships:
  - FLIGHT_SEAT (M) >---- (1) FLIGHT   : Belongs to a flight
  - FLIGHT_SEAT (M) >---- (1) SEAT     : Maps to an aircraft seat
  - FLIGHT_SEAT (1) ----< (M) BOOKING_SEAT : Reserved by booking seats

Constraints:
  - UNIQUE (FlightId, SeatId) -- Each seat appears once per flight

| IsDeleted           | BIT             | NO   |        | Soft delete flag      |

  - BOOKING (M) >---- (1) USER         : Made by a user

    "A tenant creates many discount codes; a discount belongs to one tenant"

11. AIRCRAFT (1) --------< (M) FLIGHT
    "An aircraft is assigned to many flights; a flight uses one aircraft"

12. FLIGHT (1) --------< (M) FLIGHT_SEAT
    "A flight has many flight seats; a flight seat belongs to one flight"

13. SEAT (1) --------< (M) FLIGHT_SEAT
    "A seat maps to many flight seats; a flight seat references one seat"

14. FLIGHT (M) --------< >-------- (M) OFFER  [via FLIGHT_OFFER]
    "A flight can have many offers; an offer can apply to many flights"
    Junction table: FLIGHT_OFFER (FlightId, OfferId)

    "A user makes many bookings; a booking belongs to one user"

16. FLIGHT (1) --------< (M) BOOKING

17. BOOKING (M) --------< (0..1) DISCOUNT
    "A booking may use one discount code; a discount can be used in many bookings"

18. BOOKING (1) --------< (M) BOOKING_SEAT
    "A booking includes many booking seats; a booking seat belongs to one booking"

19. FLIGHT_SEAT (1) --------< (M) BOOKING_SEAT
    "A flight seat is reserved by many booking seats (only 1 confirmed)"
